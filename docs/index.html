Sighting

Videos sichten, Notizen mit Timecode & Screenshot automatisch mitschreiben, Interviews lokal transkribieren — nativ auf dem Mac.

⇩ Download für macOS Auf GitHub ansehen

Sighting.zip · macOS 14+ · nicht notariert — beim ersten Start per Rechtsklick → „Öffnen" bestätigen. Lieber selbst aus dem Quellcode bauen?

Was Sighting kann

Gebaut für alle, die Rohmaterial sichten und dabei strukturiert dokumentieren müssen — Dokumentarfilm, Journalismus, Interview-Auswertung.

✎

Automatischer Timecode + Screenshot

Sobald eine neue Notiz beginnt, fügt Sighting Timecode und Standbild automatisch ein — der Screenshot lässt sich per Schalter abstellen.

⏱

Klickbare Timecodes

Klick auf einen Timecode im Text springt im Video direkt an die Stelle zurück.

⌨

Profi-Steuerung

0,5×–2× Geschwindigkeit, Bild-für-Bild, Shortcuts wie J/K/L, Leertaste und Pfeiltasten.

●

Marker & Favoriten

Farbige Marker direkt in der Timeline setzen, mit übersichtlicher Markerliste.

🗣

Lokale Whisper-Transkription

Interviewsegmente offline transkribieren — whisper.cpp mit large-v3-turbo, keine Cloud.

⇩

Export als PDF, DOCX & CSV

Fertige Sichtungsnotizen inklusive Bilder als Dokument oder als Timecode-Tabelle exportieren.

🎞

MXF/XDCAM-Broadcast-Footage

Container wie XDCAM-MXF, die macOS nicht direkt öffnen kann, werden beim Import automatisch und verlustfrei umgepackt.

✨

KI-Bildbeschreibung auf Deutsch (Add-on)

Optional per Ollama, komplett offline — beschreibt Standbilder und übersetzt sie automatisch ins Deutsche. Manuell oder als Vollautomatik bei jedem Marker — ohne Ollama bleibt der Rest der App unverändert.

So sieht's aus

Video oben, Notizen unten — mit automatisch eingefügten Timecodes und Standbildern.

Installation

Kein Xcode-Projekt nötig — Swift Package Manager reicht.

  • macOS 14 oder neuer (Apple Silicon empfohlen)
  • Xcode Command Line Tools (xcode-select --install)
  • Homebrew, sowie whisper-cpp und ffmpeg für Transkription und MXF-Import
  • Optional, nur für die KI-Bildbeschreibung: Ollama
# Abhängigkeiten für Transkription & MXF-Import brew install whisper-cpp ffmpeg # optional, nur für die KI-Bildbeschreibung brew install ollama brew services start ollama ollama pull moondream ollama pull qwen2.5:1.5b # App bauen und starten git clone https://github.com/fmatsch/sighting.git cd sighting ./build-app.sh open Sighting.app
